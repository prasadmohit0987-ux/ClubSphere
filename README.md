# ClubSphere

ClubSphere is a Student Club & Membership Management System.

## Features

- Student registration
- Student login
- Password hashing
- Student dashboard
- View available clubs
- View club details
- Join clubs
- Leave clubs
- View joined clubs
- SQLite database
- Automated API testing
- GitHub Actions CI pipeline

## Technology

- Node.js
- Express.js
- SQLite
- HTML
- CSS
- JavaScript
- Jest
- Supertest
- GitHub Actions
